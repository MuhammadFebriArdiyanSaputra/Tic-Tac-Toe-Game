# Tic-Tac-Toe Game

A classic two-player Tic-Tac-Toe game built with React as part of the **freeCodeCamp** Front End Development Libraries curriculum. This lab focuses on managing board state, handling user interactions, and determining win or draw conditions.

## Features

- **Interactive 3x3 Board:** Alternating turns between **X** and **O** with distinct color highlights.
- **Win & Draw Detection:** Automatically detects horizontal, vertical, and diagonal wins (`Winner: X` / `Winner: O`) as well as draw games, locking the board once the round ends.
- **Instant Reset:** Includes a reset button (`#reset`) to clear the board and start a new match at any time.

## Technologies Used

- React (`useState`)
- JavaScript (ES6+)
- HTML5 & CSS3 (CSS Grid)

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` in your browser using a local server (such as VS Code Live Server) to play the game.
